## One-shot Run

```typescript
import { run } from '@factory/droid-sdk';

const result = await run('What is 2+2?', {
  cwd: process.cwd(),
});

console.log(result.text);
```

`run()` creates a session, sends one message, closes the session, and returns a `DroidResult`.
Transport and startup failures can throw errors such as `ConnectionError`, `ProtocolError`, or `ProcessExitError`.
Droid turn errors are captured on the returned result as `success: false` and `error`.
`run()` accepts both session options (`cwd`, `execPath`, `modelId`, `mcpServers`, tool overrides, handlers, etc.) and message options (`images`, `files`, `outputFormat`, `abortSignal`).

```typescript
type DroidResult = {
  sessionId: string;
  text: string;
  messages: DroidMessage[];
  tokenUsage: TokenUsageUpdate | null;
  durationMs: number;
  turnCount: number;
  error: ErrorEvent | null;
  structuredOutput: JsonObject | null;
  success: boolean;
};
```

## Structured Output

```typescript
import { OutputFormatType, run } from '@factory/droid-sdk';

const result = await run('Pick a favorite number between 1 and 42.', {
  cwd: '/my/project',
  outputFormat: {
    type: OutputFormatType.JsonSchema,
    schema: {
      type: 'object',
      properties: {
        favoriteNumber: {
          type: 'number',
          minimum: 1,
          maximum: 42,
        },
      },
      required: ['favoriteNumber'],
    },
  },
});

console.log(result.structuredOutput?.favoriteNumber);
```

Structured output is requested with `outputFormat` on `run()`, `session.send()`, or `session.stream()`.
The SDK currently supports `OutputFormatType.JsonSchema`; `DroidResult.structuredOutput` is a parsed JSON object when Droid returns valid JSON for the schema.

## Multi-turn Session

```typescript
import { createSession } from '@factory/droid-sdk';

const session = await createSession({ cwd: process.cwd() });

try {
  const first = await session.send('What is this project?');
  console.log(first.text);

  const second = await session.send('What should I test first?');
  console.log(second.text);
} finally {
  await session.close();
}
```

`createSession()` returns a `DroidSession`. Use `session.send()` for aggregated results, and always call `session.close()` when done.

Useful `createSession()` options include:

```typescript
type CreateSessionOptions = {
  execPath?: string;
  execArgs?: string[];
  cwd?: string;
  env?: NodeJS.ProcessEnv;
  modelId?: string;
  autonomyLevel?: AutonomyLevel;
  interactionMode?: DroidInteractionMode;
  reasoningEffort?: ReasoningEffort;
  specModeModelId?: string;
  specModeReasoningEffort?: ReasoningEffort;
  mcpServers?: DroidMcpServerConfig[];
  enabledToolIds?: string[];
  disabledToolIds?: string[];
  permissionHandler?: ClientPermissionHandler;
  askUserHandler?: ClientAskUserHandler;
  abortSignal?: AbortSignal;
};
```

## Streaming a Turn

```typescript
import { createSession, DroidMessageType } from '@factory/droid-sdk';

const session = await createSession({ cwd: process.cwd() });

try {
  for await (const msg of session.stream('Explain src/session.ts')) {
    if (msg.type === DroidMessageType.AssistantTextDelta) {
      process.stdout.write(msg.text);
    }
  }
} finally {
  await session.close();
}
```

`session.stream(text, options?)` yields `DroidMessage` events until a `turn_complete` sentinel is emitted.
The same message options accepted by `send()` are supported: `images`, `files`, `outputFormat`, and `abortSignal`.

## Stream Then Collect Final Result

```typescript
import {
  createSession,
  DroidMessageType,
  type DroidMessage,
  type DroidSession,
  type ErrorEvent,
  type TokenUsageUpdate,
} from '@factory/droid-sdk';

let session: DroidSession | undefined;

try {
  const messages: DroidMessage[] = [];
  let text = '';
  let tokenUsage: TokenUsageUpdate | null = null;
  let error: ErrorEvent | null = null;

  session = await createSession({ cwd: process.cwd() });

  for await (const msg of session.stream('Find likely bugs')) {
    messages.push(msg);

    if (msg.type === DroidMessageType.AssistantTextDelta) {
      text += msg.text;
      process.stdout.write(msg.text);
    }

    if (msg.type === DroidMessageType.TokenUsageUpdate) {
      tokenUsage = msg;
    }

    if (msg.type === DroidMessageType.Error && error === null) {
      error = msg;
    }

    if (msg.type === DroidMessageType.TurnComplete && msg.tokenUsage) {
      tokenUsage = msg.tokenUsage;
    }
  }

  console.log('\nFinal text:', text);
  console.log('Messages:', messages.length);
  console.log('Token usage:', tokenUsage);
  console.log('Error:', error);
} finally {
  await session?.close();
}
```

If you do not need per-event handling, prefer `session.send()` because it performs this aggregation for you.

## Interrupt or Cancel Running Work

Use `session.interrupt()` to ask Droid to stop the active turn while you continue consuming the stream:

```typescript
import { createSession, DroidMessageType } from '@factory/droid-sdk';

const session = await createSession({ cwd: process.cwd() });

try {
  let text = '';
  let interrupted = false;

  for await (const msg of session.stream('Refactor the whole repo')) {
    if (msg.type === DroidMessageType.AssistantTextDelta) {
      text += msg.text;
      process.stdout.write(msg.text);

      if (!interrupted && text.length > 500) {
        interrupted = true;
        await session.interrupt();
      }
    }
  }
} finally {
  await session.close();
}
```

Use `AbortController` when the caller wants to cancel local waiting and reject the stream/send operation:

```typescript
import { createSession } from '@factory/droid-sdk';

const session = await createSession({ cwd: process.cwd() });
const controller = new AbortController();

try {
  setTimeout(() => controller.abort(new Error('Timed out')), 5_000);

  await session.send('Refactor the whole repo', {
    abortSignal: controller.signal,
  });
} finally {
  await session.close();
}
```

## Resume Session

```typescript
import { resumeSession } from '@factory/droid-sdk';

const session = await resumeSession('session-id', {
  cwd: process.cwd(),
});

try {
  const result = await session.send('Continue where we left off');
  console.log(result.text);
} finally {
  await session.close();
}
```

`resumeSession()` loads an existing Droid session and returns a `DroidSession`.
It throws `SessionNotFoundError` if the session ID does not exist.

## SDK-backed MCP Tools

```typescript
import { z } from 'zod';

import {
  ToolConfirmationOutcome,
  createSession,
  createSdkMcpServer,
  tool,
} from '@factory/droid-sdk';

const sdkTools = createSdkMcpServer({
  name: 'sdk-tools',
  tools: [
    tool(
      'favorite_number',
      'Returns a favorite number for a person',
      { name: z.string() },
      ({ name }) => `${name}'s favorite number is 42.`
    ),
  ],
});

const session = await createSession({
  cwd: process.cwd(),
  mcpServers: [sdkTools],
  permissionHandler: () => ToolConfirmationOutcome.ProceedOnce,
});

try {
  const result = await session.send(
    'Use the favorite_number tool for Ada and tell me the answer.'
  );
  console.log(result.text);
} finally {
  await session.close();
}
```

`createSdkMcpServer()` starts an in-process MCP server managed by the SDK lifecycle.
Use `tool()` for typed tool definitions; Zod object shapes are supported for input validation.
